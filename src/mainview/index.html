配置项说明与调整建议
Device Token目标设备和当前 App 安装实例的推送标识。开发包使用开发环境 Token，正式包使用生产环境 Token；重新安装或系统更新后 Token 可能变化。
Push Typealert 用于普通通知；background 用于静默后台刷新；voip、liveactivity 等类型必须与 App 对应能力和 Payload 结构一致。
Priority10 表示立即投递，适合用户可见通知；5 表示节能投递。background 必须选择 5。
Collapse ID可选。相同 ID 的待投递通知会被新通知替换，适合只保留最新状态；不同业务请使用不同 ID。
ExpirationAPNs 保留通知的 Unix 秒级时间戳。填写 0 表示设备暂时离线时不保留；需要稍后补发时填写未来时间。
